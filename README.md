# .github

Org-level GitHub defaults for [@theopenco](https://github.com/theopenco).

- [`profile/README.md`](profile/README.md) — the public profile page rendered at [github.com/theopenco](https://github.com/theopenco)
- `profile/assets/` — logos and product screenshots used by that page

Screenshots are mirrored from `apps/ui/public/screenshots` in
[theopenco/llmgateway](https://github.com/theopenco/llmgateway); refresh them there first, then copy across.
